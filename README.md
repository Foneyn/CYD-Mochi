# Dasai Mochi — CYD 2.8" ESP32-2432S028R port

Порт анимации из приложенного `ino full program.zip` для платы **ESP32-2432S028R (CYD 2.8")** с TFT ILI9341 320×240.

## Что перенесено
- Все 772 исходных кадра 128×64 сохранены без изменения.
- Вместо Adafruit_SSD1306 используется TFT_eSPI / ILI9341.
- Кадры масштабируются до 320×160 с сохранением пропорций и выводятся по центру.
- Целевая частота — 24 FPS (42 мс).
- GitHub Actions собирает `firmware.bin` и публикует его как workflow artifact.

## Сборка через GitHub Actions
1. Создайте пустой GitHub-репозиторий.
2. Загрузите в него всё содержимое архива (файл `platformio.ini` должен лежать в корне).
3. Откройте вкладку **Actions** и запустите **Build CYD firmware** (или сделайте push).
4. После завершения скачайте artifact `cyd-esp32-2432s028r-firmware`.

## Локальная сборка
Установите PlatformIO и выполните `pio run -e cyd-esp32-2432s028r`.

## Стандартная распиновка CYD 2.8"
| Сигнал | GPIO |
|---|---:|
| TFT SCLK | 14 |
| TFT MOSI | 13 |
| TFT MISO | 12 |
| TFT CS | 15 |
| TFT DC | 2 |
| TFT RST | -1 |
| Подсветка | 21 |

Сенсорный экран не используется. Предполагается распространённая ревизия ESP32-2432S028R с ILI9341 и указанной распиновкой; у отдельных ревизий могут быть отличия.

## Примечание
В текущей среде не удалось запустить PlatformIO и проверить результат компилятора. GitHub Actions выполнит проверку при первом push. Если дисплей вашей ревизии имеет другую распиновку/контроллер, настройки `platformio.ini` потребуется скорректировать.
