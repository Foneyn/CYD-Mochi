# Dasai Mochi — CYD 2.8" ESP32-2432S028R port

Порт анимации из приложенного `ino full program.zip` для платы **ESP32-2432S028R (CYD 2.8")** с TFT ILI9341 320×240.

## Что перенесено
- Все 772 исходных кадра 128×64 сохранены без изменения.
- Вместо Adafruit_SSD1306 используется TFT_eSPI / ILI9341.
- Кадры масштабируются до 320×160 с сохранением пропорций и выводятся по центру.
- Целевая частота — 24 FPS (42 мс).
- GitHub Actions собирает `firmware.bin` и публикует его как workflow artifact.

## Стандартная распиновка CYD 2.8"
| Сигнал | GPIO |
|---|---:|
| TFT SCLK | 14 |
| TFT MOSI | 13 |
| TFT MISO | 12 |
| TFT CS | 15 |
| TFT DC | 2 |
| TFT RST | -1 |
| Подсветка | 21 |

Сенсорный экран не используется. Предполагается распространённая ревизия ESP32-2432S028R с ILI9341 и указанной распиновкой; у отдельных ревизий могут быть отличия.
